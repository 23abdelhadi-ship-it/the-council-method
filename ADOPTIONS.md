# Adoptions & method forks — declaration template and log

The Council Method spreads by **re-implementation**, not by installation: its
measured form of adoption is the *documented method fork* — someone takes the
method (brief in an imposed format, independent round, anonymised debate by
rotation, binding decisions register, claim classification, quorum rule, a
human chair who verifies by execution) and runs it in their own host, tool, or
language. This file is the instrument that captures that indicator.

## What counts

- **Adoption** — the method run as published, on a real file or decision, with
  a public trace (a repository, an article, a session record).
- **Method fork** — the method re-implemented in another host, tool, or
  language, with a public trace naming what was taken.
- **Not counted** — stars, silent clones, private use with no public trace.
  An undocumented use may be real; it is simply not measurable, and this log
  records only what is documented.

## Declare an adoption or a fork

Copy the template below into your own repository or publication, fill it in,
and keep it public. That public declaration *is* the record — this project
accepts no pull requests (zero maintenance), so declarations are logged here
by the project owner from public links, exactly as declared, with the link as
evidence.

```markdown

- **Date**:

- **Type**: adoption / method fork / partial adoption
- **Public evidence (link)**:
- **Elements taken**: (e.g. brief format · decisions register · quorum rule ·
  claim classification · debate by rotation · chair verification by execution)

- **What it was used on**: (the kind of file or decision — no confidential content)
```
