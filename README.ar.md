# The Council Method

**هذا المشروع لا يولّد شيفرة ولا ينفّذ بوكلاء متعددين: نماذج لغوية متعددة تتداول على ملفاتك التقنية (شيفرة، قرارات، أبحاث)، وكل ادعاء مصنّف [مثبت / استنتاج / اقتراح]، وسجلّ قرارات ملزم، ورئيس بشري يحسم بالتنفيذ لا بالتصويت.**

اللغات: [English](README.md) · **العربية** (هذا الملف) · [Français](README.fr.md) · [Español](README.es.md) · [Português](README.pt.md)
وثيقة المنهج: [العربية (المصدر)](docs/METHODE.md) · [Français (المصدر)](docs/METHODE.fr.md) · [English](docs/METHODE.en.md) · [Español](docs/METHODE.es.md) · [Português](docs/METHODE.pt.md)

> نموذج واحد يعطيك رأيًا واحدًا واثقًا؛ إن أخطأ فلا شيء ينبّهك. يحوّل The Council Method السؤال إلى مؤسسة مراجعة صغيرة: جولة مستقلة، مناظرة مجهّلة، ورئيس يتحقق بالتشغيل الفعلي — يعمل فعليًا منذ نوفمبر 2026 في مراجعة مشاريع حقيقية، وهذه نسخته العامة.

## اقرأ هذا قبل التثبيت — التوقعات مسمّاة

- **ما هذا**: منهج (وثائق وقوالب وقواعد) + محرك Node صفري الاعتماديات يشغّله. ملف واحد، بلا تثبيت npm: *التثبيت هو التنزيل*.
- **ما ليس هو**: ليس واجهة محادثة، ولا إطار وكلاء، ولا مولّد شيفرة، ولا خدمة مستضافة. لا واجهة ويب ولن تكون.
- **سياسة الصيانة — صفر، بالتصميم**: يُنشر **كما هو، بنسخة 1.1 ثابتة. لا معالجة issues ولا قبول PR ولا إصدارات مستقبلية.** صفر صيانة = ثبات عقد، لا هجر. للتكييف: انسخ (fork). (سابقة موثقة: عرض «مجلس» شهير بملف واحد بلغ عشرات آلاف النجوم بهذه السياسة نفسها؛ والصيانة المجتمعية دين يرفضه هذا المشروع منذ اليوم الأول.)
- **لمن يصلح**: لصاحب قرار أخطاؤه غالية — مراجع شيفرة أو قرارات أو خطط أو أبحاث، قادر على قراءة المخرجات والتحقق من الادعاءات. لا يضيف شيئًا للأسئلة السريعة البسيطة.
- **الرئيس بشري**: المحرك لا يصدر حكمًا. إن لم يقرأ أحد ويتحقق، حصلت على آراء واثقة متعددة بدل رأي واحد.
- **مفاتيحك وكلفتك**: الطبقات المجانية تكفي (وخطّ واحد لا يحتاج أي مفتاح). لا شيء هنا يتصل ببيتنا؛ ملفاتك تذهب فقط لمزوّدي النماذج الذين تضبطهم أنت.

## أول جلسة — صفر مفاتيح، نحو 15 دقيقة

يتطلب Node ≥ 20 (مُتحقق على Node 20 و24). بلا حساب، بلا مفتاح، بلا كلفة: خطّ مدمج بلا مفتاح يُجلس المجلس.

```bash
# 1. احصل على الملفات (نزّل هذا المستودع أو انسخه)، ثم:
node moteur/conseil.mjs --init        # يثبّت brief.md وDECISIONS.md وREFERENCE.md من القوالب الموجَّهة
# 2. حرّر الملفات الثلاثة لمشروعك (القوالب تشرح ما يُكتب)
node moteur/conseil.mjs --sujet "مراجعة مقترح X" --source ./your-files/
# 3. اقرأ revues/<date>_<subject>/ — مخرجات الأعضاء الخام، تقرير الهشاشة،
#    وقالب توليف موجَّه يكمله الرئيس
```

اختياري: `node moteur/conseil.mjs --assistant-cles` يشغّل معالجًا تفاعليًا يسأل مزوّدًا مزوّدًا، **ويختبر كل مفتاح حيًّا**، ويكتب الإعداد بنفسه. و`node moteur/test-cles.mjs` يعطي تشخيصًا قراءة-فقط لكل مقعد (الحالة + سطر الإصلاح الدقيق). (قراءة-فقط = لا يعدّل شيئًا؛ لكنه يجري استدعاءات شبكة حيّة للتحقق من المقاعد وقد يستهلك حصّة.) و`--dry-run` يجمع الدوسييه بلا أي اتصال شبكي. و`--poids legere|standard|complete` يختار وزن الجلسة (أدناه).

## حاجة ← عملية ← نتيجة مسمّاة

| حاجتك | العملية | النتيجة المسمّاة التي تحصل عليها |
|---|---|---|
| رأي ثانٍ لا يكون صدى | الجولة 1: مراجعات مستقلة، الأعضاء عميان عن بعضهم | بنود مرقّمة (F-01...) بأدلة (ملف:سطر) وتصنيفات ادعاء |
| خلاف تستعمله لا يُذاب | الجولة 2: مناظرة مجهّلة بالتناوب | موافقات/معارضات بأسباب؛ وحقل توليف «خلافات محفوظة بنصّها» |
| حماية قراراتك السابقة من التجاوز الصامت | سجلّ قرارات ملزم يُقرأ في كل جلسة | أي اقتراح مخالف يُوسم «مخالف لقرار مسجل رقم N» |
| حماية من استشهاد المجلس بنفسه | قاعدة ضد الاستشهاد الذاتي مسمّاة + وسوم منشأ مضبوطة عند الكتابة | لا يصير ادعاء [مثبت] إلا بدليل من خارج المجلس |
| جلسة فشلت بصمت | قاعدة النصاب | الجلسات دون 3 ردود جوهرية تُوسم **QUORUM_NON_ATTEINT** — آثار لا حكم |
| معرفة إن كان المجلس مصيبًا | سجلّ النتائج اللاحقة | موقف + احتمال يُسجّلان عند الإغلاق؛ و«ما حدث فعلًا» يُلحق لاحقًا بلا إعادة كتابة |

## كيف يختلف — مقارنة بنيوية مجمّدة

|  | الموضوع المراجَع | الحوكمة (من يحسم وكيف) | التتبعية | صيغة النشر |
|---|---|---|---|---|
| llm-council (Karpathy) | أسئلة محادثة | نموذج قاضٍ يرتّب أجوبة مجهّلة | ترتيب؛ بلا تصنيف ادعاءات ولا سجلّ قرارات | تطبيق واحد، صفر صيانة |
| منهجيات المواصفات (Spec Kit، BMAD) | بناء برمجيات من مواصفات | عملية المواصفات نفسها | وثائق وقوالب؛ بلا سجلّ قرارات ملزم مفروض وقت المراجعة | عدّة بخطوط إصدار وصيانة مجتمعية |
| **The Council Method** | **ملفاتك التقنية الموجودة: شيفرة، قرارات، أبحاث، خطط** | **رئيس بشري، بالتنفيذ — أبدًا بالتصويت** | **تصنيف ادعاءات إلزامي + سجلّ قرارات ملزم + وسوم منشأ + قاعدة نصاب** | **وثائق منهج + ملف واحد صفري الاعتماديات؛ صفر صيانة، تعاقديًا** |

لم نجد — في تعداد كامل لأدوات تداول المجالس لا في عيّنة — أي منافس يجمع العناصر الأربعة: سجلّ قرارات ملزم، تصنيف ادعاءات إلزامي، رئيس يتحقق بالتنفيذ، وقاعدة نصاب للجلسة.

## أوزان الجلسات

- **خفيفة** — جسر دخول وعرض: جولة أولى فقط، صيغة أخف، صرامة تصنيف كاملة.
- **قياسية** — الافتراضي: صيغة كاملة وجولتان.
- **كاملة** — تدقيق: قياسية + تقرير هشاشة مفصّل + سطر كلفة/جهد الجلسة.

التدرّج يوازن الجهد مع رهان القرار؛ إرشاد موثّق لا قانون مرقّم.

## بابان

1. **المنهج أولًا** (موصى به لأصحاب القرار): اقرأ `docs/METHODE.md`، خذ قوالب `docs/`، وشغّل الجلسات بمهارة المضيف الواحد في `skills/` — المحرك مشغّل اختياري يديره لك وسيط تقني إن لزم.
2. **المحرك**: `moteur/conseil.mjs` يؤتمت البروتوكول كاملًا (تجميع دوسييه ببصمات، الجولتان، أختام هوية النموذج الذي خدم كل ردّ فعلًا، وسم النصاب، تقرير الهشاشة، قالب التوليف الموجَّه).

جلسة مثال كاملة اصطناعية بالكامل — أشخاص وشركة وموضوع من اختراعنا، ومخرجات محرك حقيقية — في `examples/session-demo/`.
